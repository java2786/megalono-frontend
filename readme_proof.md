# Guiding Principle

Version 1 should answer:

"Can this person solve my problem?"

Version 2 should answer:

"This person is an authority in enterprise software engineering."

Do not delay deployment waiting for Version 2.
Launch early with strong fundamentals, then continuously add evidence and engineering assets over time.
